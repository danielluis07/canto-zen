# Canto Zen — page & section spec

## Destination

A written page-and-section spec for the whole Canto Zen storefront: every route, its sections in order, and for each section its purpose, rough layout shape, pt-BR copy direction, and the data it needs — navbar and footer included. Done when a build session can implement any page without inventing anything.

## Notes

- **Domain**: fictional Brazilian home-furniture e-commerce. UI/UX only — no backend, no real payment.
- **Settled before charting**:
  - Destination is a **spec**, not built pages. Building is a separate effort.
  - Scope is **browse + cart + checkout**. No auth/account/orders/wishlist.
  - Copy is **pt-BR**. `app/layout.tsx` currently hardcodes `lang="en"` — the spec supersedes it.
  - **Brand direction is in scope** as an early ticket (mood/palette/type/density), not a full brand kit.
  - Catalog is **room-primary, type-as-filter** (Sala, Quarto, Cozinha, Escritório). *Varanda was dropped while resolving the route inventory — four rooms, not five.*
  - Non-commerce surfaces: **editorial** — Inspirações, plus Sobre/Contato and a single shared policy template.
  - Checkout is **single-page**, accordion sections + sticky order summary.
  - **No dark mode.** One warm light identity.
  - **No payment.** The pay action surfaces a clear "this is a concept" disclosure.
  - Spec resolution: purpose + layout shape + copy direction + data needs per section. Contested layouts become `prototype` tickets rather than inflating every entry.
- **Skills every session should consult**: `/grilling`, `/domain-modeling`. Add `/frontend-design` for anything visual, `/prototype` for prototype tickets.
- **Spec output lives in** `docs/spec/`, one file per page. Ticket resolutions point at it.

## Decisions so far

- [Brazilian e-commerce UX conventions](tickets/004-br-ecommerce-conventions.md) — frete is quoted per-CEP on the *product* page as a list of options; every price shows both an à-vista and a financed total (`{N}x de R$ {v} sem juros`); Pix-first payment with a discount badge that is **optional to offer and mandatory to disclose** (*corrected by [Legal copy verification](tickets/019-legal-copy.md) — this line originally read "legally-required discount badge", conflating Lei 13.455 art. 1º, which authorises the differentiation, with Lei 10.962 art. 5º-A, which requires disclosing it*); checkout runs Identificação → Entrega → Pagamento with CPF and CEP-autofill; footer must carry razão social + CNPJ + address and an ostensive 7-day arrependimento notice; furniture adds montagem-as-add-on, bulky-item access disclosure, and L × P × A dimensions. Full detail and citations in [`docs/research/br-ecommerce-conventions.md`](../docs/research/br-ecommerce-conventions.md).

- [Route inventory & URL structure](tickets/001-route-inventory.md) — rooms are top-level (`/sala`, `/quarto`, `/cozinha`, `/escritorio` — **Varanda dropped**, four rooms); products are flat at `/produtos/[slug]`; type is a path segment (`/sala/sofas`) with every other facet as pt-BR query state, room × type pairs enumerated per room and 404 otherwise; `/produtos`, `/colecoes/[slug]`, `/inspiracoes/[slug]`, `/carrinho`, `/checkout`, `/pedido-confirmado`, `/sobre`, `/contato`, `/politicas/[slug]` × 4. Breadcrumbs read a product's primary room, which hands a field to [Product data shape](tickets/003-product-data-shape.md). Full table in [`docs/spec/rotas.md`](../docs/spec/rotas.md).

- [Brand direction](tickets/002-brand-direction.md) — **high-end atelier in japandi register, quiet with one bold move**, and that move is *a régua*: a hairline rule with end ticks carrying a real cm figure along every featured piece, chosen because the cota is ornament and data at once. Palette is ink/reboco/kozo/carvalho/fio with **índigo `#223244` as the sole accent** — terracotta and `#F4F1EA` creams ruled out as the category default; type is **Zen Old Mincho** (display only) + **Schibsted Grotesk** (body, UI, tabular figures); zero radius, no UI shadow, 1px hairlines, and the only curve or shadow in the identity lives inside the photograph, which is always raking late-afternoon light on raw plaster with the piece alone. Atelier vs. the commerce realism in [Brazilian e-commerce UX conventions](tickets/004-br-ecommerce-conventions.md) resolved as **voice, not presence** — every price, parcelamento and Pix badge stays, set in the annotation voice rather than shouted; no "sob consulta". Full direction in [`docs/spec/marca.md`](../docs/spec/marca.md); three compared directions captured on branch `prototype/brand-direction`.

- [Product data shape](tickets/003-product-data-shape.md) — **a variant is not a thing**: one product record per *acabamento* (`poltrona-lina-linho-cru` and `poltrona-lina-boucle-carvalho` are two products), sharing a thin routeless `familia` entity that only names the PDP's "outros acabamentos" strip — the sole reading consistent with the slug already fixed by [Route inventory & URL structure](tickets/001-route-inventory.md). Products store **physical facts plus one authored `precoTabela`**; à-vista price, Pix badge, parcelamento, montagem price, garantia and the CEP-quoted frete are all **derived** from a store-wide `politicas` object and a mock cubed-freight rule. `nome` stays clean — the headline cm lives in the **régua**, and images carry `cotas[]` reading `medidas`, which makes the "no empty régua" prohibition enforceable in the type. Medidas are a mandatory L × P × A trio plus an open extras list, with `embalagem` separate; `disponibilidade` is a three-state enum, never a stock count; taxonomy is **entities** (`Ambiente` holding its curated `tipos[]`, `Tipo`, `Cor`, `Material`, `Colecao`, `Familia`) keyed by slug. **No ratings, no synthetic ids, no short-description field.** Full shape in [`docs/spec/produto.md`](../docs/spec/produto.md); vocabulary in [`CONTEXT.md`](../CONTEXT.md).

- [Navbar](tickets/005-navbar.md) — **no search** (the `?q=` reserved by [Route inventory & URL structure](tickets/001-route-inventory.md) goes unused, and the results surface is ruled out of scope rather than graduating), and the mega menu wins in its **narrowest** form: each room label opens a single 260px column of that room's curated tipos plus "Ver tudo em {Ambiente}", nothing else — a full-bleed panel carrying a featured piece lost because repeating the régua above every page spends the gesture `marca.md` rations to two per screen. Five items (four rooms + Inspirações) plus the cart, **left-grouped and asymmetric** with the right gutter left empty; **zero icons at every breakpoint**, so the cart is the word `CARRINHO` with a tabular `(n)` that vanishes at zero and the mobile trigger is the word `MENU`. Wordmark in Mincho as the **single registered exception** to "never for interface". Sticky at one constant 72px height — no shrink, nothing for [Motion & transition conventions](tickets/017-motion.md) to undo — and the active room signals with a **1px ink rule, not índigo**, because a product page already spends índigo twice; a product page marks no nav item at all. Hands [Cart sections](tickets/010-cart.md) the constraint that this affordance is a link, never a drawer trigger. Full spec in [`docs/spec/navbar.md`](../docs/spec/navbar.md); three panel shapes compared on branch `prototype/navbar` (commit `1efb9a1`).

- [Footer](tickets/006-footer.md) — **bloco substancial mas textual**, sem fotografia: quatro zonas em `--plaster` (fecho em Mincho + newsletter · três colunas de link mais **Atendimento como coluna própria** · marcas · bloco legal recuado em `--kozo`), assimétricas à esquerda. O rodapé é a **única exceção registrada** à regra de zero ícones de [Navbar](tickets/005-navbar.md) — bandeiras de pagamento e marcas de Instagram/Pinterest entram, monocromáticas em `--muted` a 18px, as de rede **sem link** e com o handle em texto ao lado; **selos de terceiros (Reclame Aqui, Ebit, PCI) ficam fora** por serem credenciais de um CNPJ real. Razão social, CNPJ, IE e endereço são **fictícios e concretos**, nunca placeholders; o aviso de arrependimento é **prosa autônoma** no bloco legal, contando da data de montagem quando contratada. Newsletter entra como `AVISO DE NOVAS PEÇAS`, sem desconto nem checkbox; mobile empilha **sem acordeão**. Entrega a [Checkout sections](tickets/011-checkout.md) um **rodapé reduzido** já especificado. Spec completo em [`docs/spec/rodape.md`](../docs/spec/rodape.md).

- [Home page sections](tickets/007-home.md) — **sete seções**: herói de peça única → ambientes → três peças com preço → coleção → banda de serviço → inspirações → a marcenaria. A home **abre com uma peça, não com os ambientes** (abrir com quatro ambientes é abrir com uma taxonomia), limitada a `78vh` para que os ambientes fiquem visíveis acima da dobra. O **orçamento de régua é mais duro que a regra da marca — exatamente duas na página inteira**, herói (`largura`) e abertura da coleção (`{n} PEÇAS`, derivado), proibida nas outras cinco seções, porque a home é a única página que ensina o que o gesto significa. Duas rações gastas na tira de destaques: o papel **Preço fica reservado ao herói e à PDP**, e o **selo Pix não renderiza por card** (três selos = três índigos numa tela, que `marca.md` declara errado) — vira uma linha única de política. A **banda de serviço substitui prova social** e fica no *meio* da página, porque as seções 4/6/7 são todas imagem-mais-texto e rimariam três vezes; Inspirações vira **linhas, não cards**, pelo mesmo motivo. **Sem newsletter** (rodapé), **sem Contato**, **sem CTA de fecho nem repetição dos ambientes**. Toda seleção é **autorada** num `ConteudoHome`; a peça do herói fica como *slot* com restrições, não como peça nomeada. Adição aditiva a [Product data shape](tickets/003-product-data-shape.md): `Ambiente` ganha `imagem: { src, alt }`. Spec completo em [`docs/spec/home.md`](../docs/spec/home.md).

- [Room landing & product listing sections](tickets/008-catalog.md) — **um template para as quatro rotas de listagem**; a landing de ambiente é cabeçalho textual + banda de tipos sobre a mesma grade, **sem fotografia** (a foto de ambiente já é gasta na home fazendo roteamento). A decisão mais consequente: **a régua da página é a contagem de resultados** (`{n} PEÇAS`, uma só, abrindo a grade) — resolve de uma vez o resultado visível e o teto de duas por tela, com **régua por card proibida** e a comparação de escala compartilhada descartada por obrigar o sistema de imagem a uma referência comum; em resultado zero **ela não renderiza**, porque `0 PEÇAS` anota uma grade inexistente. Filtros em **barra horizontal**, não trilho lateral: cor e material múltiplos any-match, preço em quatro faixas fixas de loja (sem slider), aplicação imediata e **estado no próprio gatilho**, não em fichas. Ordem tem três tokens — `curadoria` (padrão, novo `Produto.ordem`), `menor-preco`, `maior-preco`. **Paginação numerada de 12**, não scroll infinito, que tornaria inalcançável o rodapé legalmente obrigatório. O card herda a home com duas diferenças: **entra a largura em cm** (a promessa que `produto.md` fez ao tirar o cm do `nome`) e **sai o parcelamento**, que vira uma linha de política por listagem; esgotado aparece e ordena por último, sem véu. Coleção não tem filtro nem ordem — a sequência é o ato editorial. Adições aditivas: `Ambiente.descricao`, `Produto.ordem`. Spec completo em [`docs/spec/catalogo.md`](../docs/spec/catalogo.md).

- [Product detail page sections](tickets/009-product-detail.md) — **sete seções**: breadcrumb → bloco de compra → descrição → medidas → ficha técnica → entrega e acesso → fecho, com `ambientada` e `detalhe` entrando como quebras de largura total entre elas. A decisão central é como escala se comunica: **uma elevação técnica cotada** — a régua em expressão plena, escolhida contra foto-sozinha, silhueta humana e widget "cabe no meu espaço" — e ela mora em `Familia.desenho`, porque geometria não muda com o tecido, o que **deleta `'escala'` de `Imagem.papel`** (única reversão do ticket) e cria o invariante *mesma família ⇒ mesmas medidas*. `Familia` também ganha `designer`, fechando a lacuna que `marca.md` §1 abriu sem campo para segurá-la, e `Material` ganha `cuidados`, **derivado** em vez de autorado por peça. **O buy box não é sticky e não há barra fixa no celular** — cromagem persistente cobriria justamente o desenho e a tabela de medidas; em troca, `papel` de imagem vira **instrução de posição**, o que mata a galeria de miniaturas e torna a página determinística a partir dos dados. Buy box: nome (a única linha Mincho da página) → preço/Pix/parcelamento → outros acabamentos como amostras de `Cor.amostra` → disponibilidade → `COMPRAR` → CEP → montagem; **sem stepper de quantidade** (é do carrinho), **sem avise-me**, **sem quem-viu-também-viu** — o fecho é um link para listagem real, que é navegação e não sugestão fabricada. `COMPRAR` **não navega**: vira linha de confirmação e o contador da navbar responde, já que [Navbar](tickets/005-navbar.md) tirou a gaveta de cima da mesa. CEP fica **abaixo do CTA** (a tabela de opções o empurraria para fora da tela), erra sem cor, e é **lembrado pela sessão** — restrição entregue a [Cart sections](tickets/010-cart.md) e [Checkout sections](tickets/011-checkout.md). Montagem tem **um só endereço**: preço derivado junto dos quatro fatos que o justificam. **Régua: exatamente duas na página** — a cota do `principal` e o desenho. Medidas e Ficha técnica dividem-se por **espécie de fato**, número vs. atributo, o que move `medidasExtras` para Medidas e `itensInclusos` para a Ficha. Spec completo em [`docs/spec/pagina-produto.md`](../docs/spec/pagina-produto.md).

- [Cart sections](tickets/010-cart.md) — page, never a drawer (already fixed by [Navbar](tickets/005-navbar.md)), and the page is the **first surface in the system with no régua** — an authored absence, since the only figures available to annotate are a summed-cm (absurd) and an item count the reader can obtain by counting the lines, which would make the gesture decorative; índigo is therefore spent exactly once, on the Pix badge. **Thumbnail in, width in cm out** — opposite calls that look alike: one Produto per acabamento means two finishes share a `nome` and differ only in a photograph, so the image catches the highest-frequency error the data shape permits, while the cm debt [Room landing & product listing sections](tickets/008-catalog.md) took on is paid where a piece is *being chosen*, not where it already is. **Montagem is an attribute of the line, not a sibling line**, editable here — which resolves a live contradiction between [`pagina-produto.md`](../docs/spec/pagina-produto.md) §2.8 and §11 in favour of §11, and §2.8 was corrected in place. **Frete is stated but never summed**: one `A PARTIR DE` estimate for the session CEP, outside the arithmetic, because a figure inside the total is a promise that would move once the modality is chosen in checkout. **No delivery groups** — per-line prazo annotation plus one synthesising sentence, since visual grouping reorders the list under the reader. Text stepper and the word `REMOVER`, **no undo**, no `×`; an `esgotado` line **stays, is marked, still counts in the total and blocks the CTA**; resumo **sticky on desktop, no fixed mobile bar** (the PDP's refusal was about what the chrome would cover, and here it would cover its own destination). **Empty cart resolved**: one line plus a single link to `/produtos`, full footer kept. Out: coupon, cross-sell, saved-for-later. Also fixes the **mock freight rule** [Product data shape](tickets/003-product-data-shape.md) deferred — six CEP-prefix regions, base + per-kg, cubed weight at /6000, agendada at +R$ 100. Full spec in [`docs/spec/carrinho.md`](../docs/spec/carrinho.md).

- [Checkout sections & the concept disclosure](tickets/011-checkout.md) — the disclosure is **an interstício**: `FINALIZAR PEDIDO` runs a 1500ms silent processing beat that resolves not into a receipt but into a full-bleed Mincho statement (`Nada foi cobrado.`), with the complete order record one click behind it — a **phase of `/checkout`, not a route**, so `rotas.md` is unchanged. Staging the admission is what frees `/pedido-confirmado` to be a competent record rather than a surface fighting to carry a caveat; the confirmation-leads variant lost because `Pedido nº —` reads as a rendering bug, the disclose-before-the-click variant because a notice inside a form is read as fine print, and a persistent site-wide banner was refused unprototyped for having no slot in an identity that spends its emptiness deliberately. Sections are a **sequential accordion with soft lock**, collapsing to summary lines with `ALTERAR`; **CPF check digits validate for real**, CEP autofills from a **fixture table**, and **no PF/PJ toggle** despite the Escritório room. Payment is **Pix + cartão, no boleto**, and the honesty rule the page turns on is **no QR code on either surface and no countdown** — a scannable square resolving to nothing would be the store's most dishonest object, the fourth refusal of a fabricated artefact. Selecting the freight modality **visibly recomputes the total**, which is the payoff [Cart sections](tickets/010-cart.md) bought by keeping frete outside the cart's arithmetic. **Selection resolves in ink, never índigo**, so the single coloured thing on a payment screen is the legally required Pix disclosure; **no régua** on any of the three surfaces. Chrome is a **wordmark-only navbar** plus the reduced footer already specified, with a **sticky mobile total bar** — the one place the cart's refusal of fixed mobile chrome does not transfer. CTA is `FINALIZAR PEDIDO`, never `PAGAR`. The cart **clears at the transition** and `/pedido-confirmado` **redirects on cold arrival**. Full spec in [`docs/spec/checkout.md`](../docs/spec/checkout.md); three directions on branch `prototype/checkout-disclosure` (commit `a60d4da`).

- [Inspiracoes sections](tickets/012-inspiracoes.md) — **one genre, four articles, set closed**: an `Artigo` is *a room, composed*, one per Ambiente, and the store never publishes a fifth or a second kind — single-genre being the whole defence against the blog template, and it spends [Brand direction](tickets/002-brand-direction.md)'s single photographic exception exactly where it was granted. The surface's identity claim is **two refusals**: Inspirações is the only page in the store with **no price and no régua** — the two things every other surface asserts — the régua being the second authored absence after [Cart sections](tickets/010-cart.md), since the room's dimensions are architecture the store has no data for (fifth refusal of a fabricated artefact) and a cota on one piece inside a group shot is arbitrary where `marca.md` scopes the gesture to *a featured piece*. Editorial reaches commerce through **the legend** — a line in the annotation voice beneath each photograph naming the pieces in that frame, each a link to a `Produto` (never a `Familia`) — chosen because labelling a real thing with a true fact is what the régua does, and the legend does it in words for free; **hotspots were structurally unavailable** (numbered markers banned by the ordinal ban, unnumbered ones a reveal the 120ms-and-nothing-else motion spec cannot describe) and a card strip would import `catalogo.md`'s card and drag price back. Photography admits **no human trace** — binding, because [Product detail page sections](tickets/009-product-detail.md) refused a human figure for scale *citing this rule as having no exception outside Inspirações*. Index is **four uniform rows**, `home.md` §6 at page scale so the home is a literal excerpt; card grid refused, lead-plus-rows refused as hierarchy by recency. Article is a **fixed skeleton with exactly three photographs**, preserving the determinism [Product detail page sections](tickets/009-product-detail.md) bought, and closes on **one link to the room listing**. Housekeeping: **`?ambiente=` retired unused** (second after `?q=`), and the **empty index resolves by impossibility** — the four articles are structural, not data that can be absent. New `Artigo`/`FotoArtigo` entities, purely additive. Full spec in [`docs/spec/inspiracoes.md`](../docs/spec/inspiracoes.md).

- [Institutional pages](tickets/013-institucional.md) — **one rule across the three surfaces: the institutional pages are typographic, with no photography at all** — the third *ausência autorada* after the cart's régua and Inspirações' price, and it keeps `inspiracoes.md`'s room-shot exception at exactly one. `/sobre` is a **manifesto, and specifically the page of refusals**: five statements, four refusals plus one affirmation (`Não temos estoque.` … `O que sai daqui é assinado.`), because refusals are the one thing [Home page sections](tickets/007-home.md) §7 structurally cannot do — it is a selling page — and each refusal explains a price, which is how the atelier position gets earned rather than asserted; the essay reading would have made Sobre a fifth `Artigo`, and *method* was refused and **relocated** to `/politicas/entrega-e-frete` as facts. That choice forces four consequences: a **registered Mincho exception** (five `Display L` statements against `marca.md` §4's one-per-page, paid for by Sobre having **no page title** — the first statement is the `<h1>`), **final shippable copy** rather than direction (the only spec in the map to do so, since here the wording *is* the structure), **no CTA** — the page stops — and **exactly one régua, `DESDE 2014`, closing the page**, legal without an object because `marca.md` §2 lists *collection year* among valid figures. **Two refusals of fabricated credentials**: no founder biography or portrait (a fictional life story outweighs the QR code [Checkout sections & the concept disclosure](tickets/011-checkout.md) refused) and no designer roster (detached from a `Familia` it becomes the object [Footer](tickets/006-footer.md) refused with Reclame Aqui), leaving the no-person photography rule exceptionless as [Product detail page sections](tickets/009-product-detail.md) assumed. `/contato` is **form → showroom with the channels omitted** (the footer holds the channel, this page holds the form — repeating them would make it quote its own footer); three fields only, and on submit it **swaps in place** to `Nada foi enviado.`, the sixth refusal of a fabricated artefact and deliberately *not* checkout's interstício, whose 1500ms beat was earned by an expectation a contact form does not carry. The **showroom is real, with no embedded map** and an agendamento line that is statement 1 paying off. The **policy template** is title + date + non-sticky side index + document, **accordion refused** for hiding ostensive text, index only at **4+ sections**, **same layout but per-page headings**, and it fixes **content points, not statutory wording** — so the legal-verification pass now covers **four** surfaces. New store-wide `Loja` constant and enumerated `Politica`; `/sobre` is the **only page in the store with no data dependency**. Full spec in [`docs/spec/institucional.md`](../docs/spec/institucional.md).

- [Imagery system](tickets/014-imagery.md) — the ticket opened on a **contradiction three closed specs were carrying**: `marca.md` §7 claimed one photographic rule with one exception, naming Inspirações, while the data model already authorised three non-solo image kinds. Restated as **two genres** — *retrato* (the piece alone) and *ambiente* (a furnished room, same light, same plaster) — with Inspirações holding not the genre but the **composition**; `marca.md` §7 corrected in place, and the **no-human-trace rule generalises from Inspirações to the whole ambiente genre**, so there is now no person in any photograph in the store, which is what keeps [Product detail page sections](tickets/009-product-detail.md)'s refusal of a human scale figure valid. Ratios are **enumerated and derived, never authored** — `3:2`/`1:1`/`4:5` computed from `medidas`, plus `16:9` for `Artigo.thumb` — making "frame in the piece's real proportion" mechanically true rather than a photographer's instruction, and free-form lost because every authored composition in the store was built against a known shape. **Nothing is ever cropped**: the cart's 96px and checkout's 64px squares are `--kozo` *fields* holding a contained packshot, which **dissolves** the reconciliation [Checkout sections & the concept disclosure](tickets/011-checkout.md) handed over rather than resolving it. **The first spec in the map to add no fields at all** — two corrections instead: `Colecao.imagem` drops to `{ src, alt }`, and only `principal` is required, with `ambientada`/`detalhe` **rare and authored** against a 180–450 photograph bill. `alt` is **templated for the predictable slots, authored where it carries real information**, and no decorative image exists. Loading is another authored absence: `marca.md` §9 extends to **no fade, no blur-up, no skeleton** — a blur resolving into a photograph is a *reveal* — and a failed image leaves the flat field with **no icon and no `IMAGEM INDISPONÍVEL`**, the seventh refusal of a fabricated artefact. `Familia.desenho` is **inline SVG in the régua's own grammar**, and the footer's marks get their treatment fixed, closing the back door [Footer](tickets/006-footer.md) left open. Sourcing is **two phases**: phase 1 hotlinks Unsplash with repetition explicitly fine, phase 2 generates from a **prompt spine authored now** and lands locally. The split forced two rules of its own — **structural rules bind in phase 1 and photographic ones do not**, and **a placeholder is never evidence** — plus one carve-out: the two-acabamento família gets visibly distinct placeholders, or [Cart sections](tickets/010-cart.md)'s entire argument for its thumbnail is untestable in the phase the cart is built. Full spec in [`docs/spec/imagens.md`](../docs/spec/imagens.md).

- [Route metadata & SEO](tickets/015-route-metadata.md) — resolved on **one rule stated three times: a claim that leaves the site is held to a stricter standard than a claim made on the page**, which is [Footer](tickets/006-footer.md)'s refusal of Reclame Aqui / Ebit / PCI selos generalised past the footer — on-page the concept-store frame travels with the reader and the admission is staged where [Checkout sections & the concept disclosure](tickets/011-checkout.md) put it; in a third party's index it does not travel. **The title spends nothing** — bare name plus ` | Canto Zen`, home unsuffixed; the régua-in-the-title reading was live and lost, since mandatory `medidas` make a cm figure always *honest* but `marca.md` §2 licenses the gesture only on a photographed featured piece, and a cota as ASCII in a SERP is the gesture without its hairline. That throws the load onto **descriptions, which are derived or are an authored line the data already holds — never written for the metadata layer**, so the spec is the **second in the map to add no fields**, after [Imagery system](tickets/014-imagery.md); where there is neither authored line nor facts the surface carries **no description at all** (cart, checkout, `/pedido-confirmado`, 404 — the fourth *ausência autorada*). **The product description carries no price**, so it and the `Product` node end up carrying the same class of fact — the rule applied twice. Structured data is **facts yes, offers no**: three node types in the whole store (`Product`, `BreadcrumbList`, `Article`), with `offers` refused as the **eighth refusal of a fabricated artefact** — a price/availability node is the machine-readable form of precisely the claim the checkout is built around admitting the store cannot make — and `Organization`/`LocalBusiness` refused on a line worth keeping: **a name is not a credential; an address, CNPJ, telephone, logo or rating is**, which permits `Brand { name }` while killing the node `/contato`'s showroom would invite. Also out: `AggregateRating`, `ItemList`, `WebSite`+`SearchAction`, `sku`/`gtin`; recorded so nobody "fixes" it, **the `Product` node is deliberately ineligible for merchant rich results**. OG is the photograph **contained in a 1200×630 `--kozo` field, never cropped** — [Imagery system](tickets/014-imagery.md)'s treatment of the cart's 96px square applied to the one frame the store does not control — which makes `og:type` **never `product`** and leaves the institutional pages **no card and no fallback wordmark**. `pagina` is the **sole indexable query param**; all filter state is `noindex` and canonical to the clean path. **404 vs. empty result** is fixed as a distinction that must never swap — URL not existing (`404`) vs. state matching nothing (`200`) — handing [Error, 404 & loading surfaces](tickets/016-error-surfaces.md) a contract, not a design. Full spec in [`docs/spec/rotas.md`](../docs/spec/rotas.md) §Metadata.

Loading is **conteúdo velho** — the replaced region persists at `0.45` opacity, chrome never dims — which **widens `marca.md` §9 by exactly one entry, stated out loud** and handed to [Motion & transition conventions](tickets/017-motion.md) as settled. The ticket also **absorbed the inline field-error rule** [Checkout sections & the concept disclosure](tickets/011-checkout.md) handed it, resolving a live contradiction between the PDP's annotation voice and checkout's Corpo S in checkout's favour, and splitting field errors into **corrigível** (states the fix) and **fato** (states the store's limit). - [Motion & transition conventions](tickets/017-motion.md) — **state-only: motion may confirm that something changed or is changing, and may never announce arrival.** The régua **does not animate**, refused on §2's own test — a drawing animation states no figure while it runs, so it *is* the empty régua §2 already prohibits, moved into the time axis. §9 of [`docs/spec/marca.md`](../docs/spec/marca.md) is rewritten as a **closed list of exactly two motions** (the pointer colour transition; the stale-content dim adopted verbatim from [Error, 404 & loading surfaces](tickets/016-error-surfaces.md)) over a **closed property allowlist** (colour-carrying properties + `opacity`; `transform` refused by name as displacement, since §6 has no elevation vocabulary for it to express) — everything else in the store is a cut, and a cut needs no justification. One duration and one easing (`120ms`, `linear` — argued rather than defaulted, because at that duration a curve is sub-perceptual and `ease-out` *means* arrival, which §9.1 bans as a meaning); **the transition follows the pointer, never the keyboard**, so focus and `:active` are always cuts; **one global `prefers-reduced-motion` rule** — end state kept, interpolation dropped — which demotes the previous per-spec branch to an instance and gives every future entry a branch it cannot forget. **A delay is not motion**, so [Checkout sections & the concept disclosure](tickets/011-checkout.md)'s 1500ms beat stays a checkout constant and its wash **arrives as a cut** — a fade would dramatise the exact moment that surface exists to admit was never real work. The cart line's exit is a **cut**, against [Cart sections](tickets/010-cart.md)'s suggestion that it was the one place a transition would carry meaning: a fade-out would **invert** the dim's meaning, since `0.45` says *stale, content is coming* and a row fading to `0` says nothing is coming — the same property carrying opposite meanings on adjacent surfaces is how a small vocabulary rots. Ten standing refusals ratified once so no future surface re-argues them, including that **the photograph gains nothing on hover, anywhere**. The durable half is **§9.9: §9 declares itself closed, with an amendment protocol** (name the entry, say why no existing entry covers it, land it in §9), converting ten sessions of held discipline into structure before the build phase runs sessions in parallel. [`imagens.md`](../docs/spec/imagens.md) §6 and [`catalogo.md`](../docs/spec/catalogo.md) §6 and §9 corrected in place — they quoted the provisional wording verbatim and the quotation is now false; their conclusions were unaffected.

- [Accessibility commitment level](tickets/018-accessibility.md) — the spec **asserts no WCAG conformance**: a written commitment of nine obligations in its own words, citing no standard, because a concept store with no audit cannot support an AA claim — the difference from AA being *provenance, not altitude*, since the nine are the AA criteria the spec already meets. New [`docs/spec/acessibilidade.md`](../docs/spec/acessibilidade.md) is **normative rather than a summary**, with a precedence line (a page spec that is more specific wins; one that is weaker or silent loses) so it binds surfaces nobody has specced yet — the case that matters when the destination is a spec handed to parallel build sessions. It carries the **measured contrast table**, not a bare list, and building that table **broke the palette twice before any code existed**. `--muted` `#7A756C` measured **4.16** on `--plaster` and **3.71** on `--kozo`, below the 4.5 floor on both, with no large-text exemption available anywhere because the annotation voice is `0.6875rem` — so the store's workhorse colour failed across five specs at once; it becomes **`#6B675F`** (5.11 / 4.56), the shallowest value clearing both grounds (`#736E66` clears plaster at 4.60 and still fails kozo). The second failure the ticket did not anticipate: `--hairline` measured **1.41**, and it was the resting border of every input, the stepper and the unselected selection row — under the 3:1 boundary floor. **The resting control border becomes `--muted`** (no new token; focus still cuts to `--ink`), which repairs a jump from near-invisible to black and sharpens the palette's meaning into a rule worth keeping: **`--hairline` is decorative structure, `--muted` carries meaning** — so `--hairline` stays light, because after this it borders nothing that is a control. Darkening `--hairline` wholesale was refused (dividers are not control boundaries) and a dedicated `--field` token was refused (the lightest value clearing both grounds sat too close to `--muted`). On keyboard: `navbar.md` §6 fully specified the ambiente panel while `catalogo.md` §12's mobile sheets specified nothing, resolved as **one generic overlay rule** (Escape, focus return to trigger, focus containment, `aria-expanded`, one at a time) that the navbar's existing prose keeps duplicating in place — the rule exists for the overlays specced *after* today's two.
